# Contributors

People who have contributed to Parousia beyond its maintainers. To be listed, contribute through a pull request (see [`CONTRIBUTING.md`](.github/CONTRIBUTING.md)) and say how you'd like to be credited.

## Translations

The popup and dashboard are translated through one file per language in [`browser/src/locales/`](browser/src/locales/); [`browser/README.md`](browser/README.md#languages) explains the format and how to add a language.
